# FormaVita Marka Varlıkları

Bu klasör FormaVita'nın uygulamada kullanılmaya hazır marka dosyalarını içerir.

## Brand

- `brand/formavita-app-icon-1024.png`: iOS / App Store uygulama ikonu
- `brand/formavita-app-icon-master.png`: yüksek çözünürlüklü kaynak ikon
- `brand/formavita-logo-horizontal-light.png`: Soft Lilac zeminli yatay logo
- `brand/BRAND_GUIDE.md`: renk, tipografi ve kullanım kuralları
- `brand/IMAGEGEN_PROMPTS.md`: görsel üretim promptları

## Fonts

- `fonts/Manrope-VariableFont_wght.ttf`: ExtraLight–ExtraBold aralığını içeren değişken marka fontu
- `fonts/OFL.txt`: Manrope SIL Open Font License 1.1 lisansı

Arayüzde iOS sistem fontu olarak SF Pro Rounded / SF Pro Text kullanılabilir. Bunlar Apple sistem fontları olduğu için proje içine kopyalanmamıştır. Platformlar arası marka fontu olarak Manrope kullanılmalıdır.
